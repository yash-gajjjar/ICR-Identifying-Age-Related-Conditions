# Identifying Age-Related Conditions

A binary classification project based on the [Kaggle ICR competition](https://www.kaggle.com/competitions/icr-identify-age-related-conditions).

## Problem

Predict whether a participant belongs to the competition's positive class, indicating one or more of the specified age-related conditions, using the supplied health-measurement features.

## Modelling workflow

The repository currently provides the competition context. The notebook should be treated as the source of truth for:
- Data cleaning and missing-value handling.
- Feature preprocessing and selection.
- Validation strategy.
- Model training and selection.
- Competition metric and final results.

## Limitations

This is a competition modelling exercise, not a clinically validated diagnostic system. Predictions should not be used for medical decisions.
